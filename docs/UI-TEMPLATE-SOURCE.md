## Reuse policy

This public site reused the donor visual direction and implementation conventions: Next.js foundation, design tokens, responsive layout, navigation/header/footer patterns, buttons, cards, forms, status labels and SEO-capable public structure.

The donor repository was not copied wholesale. Internal dashboard routes, mock admin data, private migration notes, local build residue, donor-specific README content, generic assets and implementation residue were excluded from this public repository.

## Public safety

No secrets, customer data, fake testimonials, fake provider integrations or private donor context are intentionally included.
